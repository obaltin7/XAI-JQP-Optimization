# These versions were verified together with the torch 2.4.1+cu124 / transformers 4.44.2 pins
# (Windows, Python 3.10, RTX 2060: quantize a random mini Mistral -> save ->
# transformers.from_pretrained -> forward pass; both GPTQ and AWQ pass). Why these versions:
#   * autoawq 0.2.5        : requires torch>=2.0.1 (0.2.6 pins torch==2.3.1; 0.2.7+ requires torch>=2.5.1 or
#                            transformers>=4.45 -> incompatible with the pins)
#   * autoawq-kernels 0.0.8: built for torch>=2.4.1 (0.0.9 requires torch>=2.5.1 and would upgrade torch)
#   * auto-gptq 0.7.1      : latest release; wheels only for cp38-cp311 (NO wheels for Python 3.12+).
#                            The CUDA kernels in the PyPI wheel do not load with the torch 2.4.1 ABI
#                            ("CUDA extension not installed") -> falls back to the slower but correct torch path.
#   * peft 0.12.0          : auto-gptq 0.7.1 cannot be imported with current peft (PEFT_TYPE_TO_MODEL_MAPPING)
#   * gptqmodel            : NOT USED -- the current release requires torch>=2.8 + transformers>=5.14, sdist only
#

#     /workspace/.venv-quant/bin/pip install -r requirements-quant.txt
